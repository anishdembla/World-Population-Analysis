# World-Population-Analysis
Power BI data visualization project analyzing global population trends (1970–2022) using interactive dashboards.

## Tools & Technologies Used
- Power BI
- Microsoft Excel
- CSV Dataset

## Project Objective
The objective of this project is to analyze historical world population data to identify growth patterns, rank change throughout the years, regional differences, and long-term demographic trends using interactive Power BI dashboards.

## Key Insights
- Asia remains the most populous region throughout the analyzed period (Mostly China & India).
- UAE shows the highest population growth rate over time.
- Europe demonstrates relatively stable or declining population trends.
- Significant differences exist in population growth patterns across regions.
