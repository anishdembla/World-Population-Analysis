# World-Population-Analysis
Power BI data visualization project analyzing global population trends (1970–2022) using interactive dashboards.

## Tools & Technologies Used
- Power BI
- Microsoft Excel
- CSV Dataset

## Project Objective
The objective of this project is to analyze historical world population data to identify growth patterns, rank change throughout the years, regional differences, and long-term demographic trends using interactive Power BI dashboards.

## Key Insights
- Asia remains the most populous region throughout the analyzed period (Mostly China & India).
- UAE shows the highest population growth rate over time.
- Europe demonstrates relatively stable or declining population trends.
- Significant differences exist in population growth patterns across regions.
- In total 98 countries have experienced significant population growth, leading to noticeable improvements in their population rankings, it makes total 41.90% of the countries in population growth.
- Population growth is not uniform across regions, with some countries growing rapidly while others show slow or negative trends, like 31 countries (13.25%) have showed no signs of growth in all these years, while 105 countries (44.85%) have showed negative growth over these years (1970-2022).
- Countries with consistent long-term growth tend to gain ranking positions over time.
- Total 105 countries contribute disproportionately to overall global population increase, they show negative trend overall in the period of 52 years, while the global population has continued to rise.
